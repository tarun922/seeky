# Contributing to Seeky

Thanks for using Seeky! A couple of things to know before you open an issue
here.

## About this repo

This repo hosts **built releases only** — the installers and packages you
download from the Releases page. It does not contain the source code, so:

- ❌ There's no code here to fork or submit pull requests against.
- ✅ This is the right place for **bug reports** and **feature requests**.

If you're interested in the source itself, that lives in a private
repo for now — this page will be updated if that changes.

## Reporting a bug

Before opening a new issue, please do a quick search to check it hasn't
already been reported.

When you open one, please include:

- **Seeky version** (Help → About, or the installer filename you used)
- **OS and version** (e.g. Windows 11 23H2, Ubuntu 24.04, macOS 15)
- **How you installed it** — `.exe` installer, portable, `.AppImage`, `.deb`,
  `.pacman`, `.rpm`, or `.dmg`
- **Steps to reproduce** — what you clicked/did, in order
- **What you expected vs. what actually happened**
- **Screenshots or a screen recording** if it's visual
- **Console output, if you can get it** — on Windows, run the installed
  `Seeky.exe` from a terminal (PowerShell/cmd) instead of double-clicking it,
  and copy anything that prints when the bug happens. This is often the
  single most useful thing you can attach.

The more of this you include, the faster it can actually get looked at —
"it doesn't work" with nothing else attached usually just sits there.

## Requesting a feature

Open an issue describing:

- What you want to be able to do
- Why — what's the actual problem or annoyance this solves for you
- Any apps/features elsewhere that do something similar, if relevant

Feature requests aren't guaranteed to get built, but they are read, and
clear, specific asks (rather than "add more features") are a lot easier to
act on.

## Please don't

- Open issues for general "how do I..." questions unrelated to a bug — those
  are better suited to discussions, if enabled on this repo.
- Share pirated/illegal links or ask for help with anything outside the
  app's intended use.
- Bump old issues repeatedly instead of commenting with new info — a 👍
  reaction on the original issue is enough to show interest.

## A note on downloads

Only download Seeky from this repo's **Releases** page. Links posted
elsewhere claiming to be Seeky installers are not official and should not be
trusted.

Thanks for helping make Seeky better! 🎌
